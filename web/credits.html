Credits

This project would have been far harder without a handful of dedicated GameFAQs contributors who catalogued Warship Gunner 2 by hand: reading values off screens and typing them into text files, with no extraction tools.

Guide authors

Bill Mulrooney (GameFAQs: bmulroon)

Author of four guides, written in 2006–2007:

  • Walkthrough (v1.02, 2007), the source of the mission names, objectives, superweapon flags, rewards in points and funds, and the Inferno Mode unlock conditions
  • Weapons Reference Guide (v1.00, 2007)
  • System Reference Guide (v1.02, 2007)
  • Ship Reference Guide (v1.01, 2006)

Jeremy Kuris (GameFAQs: tankboy)

Author of two reference guides, written over 2006–2011:

  • Aircraft Reference (v1.00, 2006)
  • Mission Pickups and Rewards (v1.10, 2006–2011), the source of the flag unlock information and flag effects on the flag viewer

Save files

The 1494/1500 and 1500/1500 save files used to cross-check unlock data were shared on GameFAQs by kriskoehler.

AI assistance

This project was built with the help of Claude, which assisted in downloading and back-fitting game files onto player knowledge.

Game and tools

Warship Gunner 2 is a game by Koei (PlayStation 2, 2005–2006). All game images, names and data belong to their respective owners. This is an unofficial fan research project and is not affiliated with or endorsed by the publisher.

Research tools used: 7-Zip, mymcplus (PS2 save formats), Pillow (images) and Capstone (disassembly of the game executable).

About the guides. Each guide carries a notice that it may be used for personal purposes and may not be republished on other websites. This site does not reproduce the guides' text. Where it shows facts that came from a guide (for example how a flag is unlocked), the source is credited on the page, and we are working towards taking values from the game's own data instead. If you are one of the authors or contributors named here and would like something credited differently, or removed, please tell us.
