Boss animations

Every keyframe stored in the boss models, played back. The chips are the game's own clips, read from each model's header: a clip is a list of steps, each showing one pose for a set number of ticks. Chip names are only given where the game code that starts the clip was read (Hell Atsche and its Supports) or where it was remembered from the game (the Lord of Terror's dance); an unnamed clip's use is not known. The tick rate is assumed to be 60 per second (the Speed slider scales it, 15 = normal). "Blend steps" mixes each step into the next one, node by node, as the game's code appears to (the exact rule is assumed). Cannon aiming, beams and weapon firing are driven by code, not by clips. Drag to turn the model, scroll to zoom.
